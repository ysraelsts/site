Preciso de Excel instalado?

Para ler o PDF, não. Para fazer os exercícios, sim — o livro é escrito com o programa aberto do lado. Qualquer navegador abre o PDF.

Qual versão do Excel serve?

Microsoft Excel 2016 ou mais novo. A única exceção é o PROCX (XLOOKUP), que só existe no Excel 2021 e no Microsoft 365 — o livro avisa isso e mostra o PROCV como alternativa.

Funciona no Mac?

O conteúdo funciona; os atalhos de teclado são os do Windows e o PROCX não existe no Excel para Mac. O PROCV, que cobre os mesmos casos, está todo explicado.

Sou iniciante absoluto. Serve?

É para você. O Módulo 1 é inteiramente básico: a tela, as células, o que é linha e coluna, como a planilha pensa.

Já sei o básico. Vou perder meu tempo?

Talvez. Não é um curso de Excel avançado: não tem VBA, nem Power Query, nem Power BI. O que ele ensina bem é montar planilha que aguenta uso real — estrutura, validação e tratamento de erro.

As planilhas vêm com as fórmulas?

Vêm, comentadas linha a linha. Uma ressalva: G03_Controle_de_Vendas.xlsx tem um PROCV apontando para célula vazia e mostra #N/D de propósito — é o exercício de diagnosticar erro. Está escrito no material.

Abre no Google Sheets ou no LibreOffice?

As planilhas foram feitas e validadas no Microsoft Excel, e é para isso que o livro assume. Formatação condicional e validação de dados se comportam diferente fora do Excel. O PDF não tem problema nenhum.
